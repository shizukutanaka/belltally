# BellTally（ベルタリー）— ベルマーク集計カウンター

小学校 PTA のベルマーク担当のための、ベルマーク集計専用カウンターです。
家庭から集まった大量のベルマークを「企業番号ごとに仕分け → 点数別に枚数を数える → 会社別の明細と合計を作る」という作業を、大きなボタンとキーボードで素早く進められます。

- **単一バイナリ**: 実行ファイル1つだけ。インストール不要、依存ゼロ（Go 標準ライブラリのみ）。
- **完全オフライン**: 通信は一切しません。画面は自分のパソコンのローカルサーバー（127.0.0.1）から開きます。
- **個人データなし**: 数えるのは企業番号・点数・枚数だけです。名前や住所などは扱いません。
- **企業番号マスタ内蔵**: ベルマーク教育助成財団の協賛会社一覧に基づく現行会社（2026年11月時点）を内蔵。財団の番号統合ルール（20番→21番、46番→4番）にも対応し、旧番号のマークも自動で統合先に集計します。マスタに無い番号も番号直接入力で数えられます。

## 起動方法

```
./belltally
```

ブラウザが自動で開きます（開かない場合は表示される `http://127.0.0.1:8781` などの URL を開いてください）。終了はターミナルで Ctrl+C です。

コマンド:

```
./belltally            Web UI を起動（既定）
./belltally summary    現在の会社別合計をターミナルに表示
./belltally export csv [ファイル名]   集計を CSV で書き出す
./belltally version    バージョン表示
```

## 使い方

1. **会社を選ぶ**: 番号と会社名のボタンを押すか、番号を直接入力します。キーボードでは数字キーで番号を打って Enter でも選べます。20番・46番を選ぶと、統合先（21番・4番）に集計されます。
2. **点数を選ぶ**: マークに印刷された点数（0.5点刻み）をボタンか直接入力で選びます。
3. **数える**: 「+1」「+10」「−1」ボタン、またはキーボードの「+」（Shift同時で+10）「-」で枚数を増減します。押すたびにその場で保存されます。
4. **出力**: 画面下の集計表は会社別・点数別の明細と会社別合計、総合計を表示します。「印刷する」で集計表だけを印刷でき、「CSVをダウンロード」で整理袋・送り状への転記用の CSV を書き出せます。

## データの置き場所

集計データは端末内の1ファイルだけに保存されます。外部に送信されることはありません。

- 既定: OS のユーザー設定フォルダ配下の `BellTally/belltally.json`
  - Windows: `%APPDATA%\BellTally\belltally.json`
  - macOS: `~/Library/Application Support/BellTally/belltally.json`
  - Linux: `~/.config/BellTally/belltally.json`
- 環境変数 `BELLTALLY_DATA_DIR` を指定すると、そのフォルダに保存します。

## ビルド

Go 1.22 以降が必要です。

```
go build -o belltally .
go test ./...
```

## 注記

- 企業番号マスタはベルマーク教育助成財団の公表する協賛会社一覧に基づきますが、最新の参加状況は財団の公式情報をご確認ください。協賛会社の加入・脱退により、実際の有効な番号は変わることがあります。
- 番号統合ルールは、財団の集計案内で確認できた範囲（20番→21番、46番→4番）のみを実装しています。
- 本ソフトはベルマーク教育助成財団とは関係のない、PTA 作業の支援を目的とした独立したツールです。
